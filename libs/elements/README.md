# @angular-nx-repo/elements

Publishable aggregator for the feature libraries. The Angular host depends on
this package only.

- `elementLazyConfig` — ngx-element lazy map
- `provideElements()` — registers the shared NgRx store
- `@angular-nx-repo/elements/banner`
- `@angular-nx-repo/elements/gallery`

```sh
npx nx build elements
npx nx test elements
```
